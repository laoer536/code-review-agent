# 通用代码规范

## 命名规范
- 变量和函数使用 camelCase
- 类名使用 PascalCase
- 常量使用 UPPER_SNAKE_CASE
- 布尔变量以 is/has/should/can 开头

## 函数规范
- 单个函数不超过 50 行
- 参数不超过 4 个，超过则用对象封装
- 避免嵌套超过 3 层

## 注释规范
- 公共 API 必须有 JSDoc 注释
- 复杂逻辑需要行内注释说明意图
- 不要写显而易见的注释

## 错误处理
- 不要吞掉异常，至少要 log
- 错误信息要包含上下文（参数、状态）
- 使用自定义错误类，不要直接 throw string
